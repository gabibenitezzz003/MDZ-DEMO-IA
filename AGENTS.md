# Instrucciones de trabajo para Codex

- Trabajar de forma autónoma dentro de este repositorio y sus servicios locales.
- No pedir aprobación para inspeccionar, editar, ejecutar pruebas, iniciar servidores o usar Docker local.
- No hacer `git push`, deploy, publicar cambios ni modificar servicios remotos sin una instrucción explícita del usuario.
- Antes de proponer subir cambios, verificar localmente el flujo completo del demo.
