--- CÓDIGO COMPLETO ---

const payload = $json.body ?? $json;
const data = payload.data ?? {};
const event = payload.event ?? payload.body?.event;

if (event === 'test' || event !== 'message.received') return [];
if (data.isGroup === true || data.isStatusBroadcast === true || !data.chatId) return [];

const rawType = String(data.type ?? '').toLowerCase();
const isAudio = ['audio', 'voice', 'ptt'].includes(rawType);
const isText = rawType === 'text' || rawType === 'chat' || (!rawType && typeof data.body === 'string');
const isImage = ['image', 'photo'].includes(rawType);
const isDocument = ['document', 'file'].includes(rawType);
const isLocation = rawType === 'location' || Boolean(data.location || data.lat != null);
if (!isAudio && !isText && !isImage && !isDocument && !isLocation) return [];

const body = typeof data.body === 'string' ? data.body.trim() : '';
if (isText && !body) return [];

if (data.fromMe === true) {
  const botEcho = /^\u200B/.test(body);
  if (!isText || botEcho) return [];
}

const loc = data.location || {};
const lat = loc.lat ?? loc.latitude ?? data.lat ?? data.latitude;
const lon = loc.lng ?? loc.lon ?? loc.longitude ?? data.lon ?? data.longitude;

const messageId =
  data.id ??
  payload.idempotencyKey ??
  payload.deliveryId ??
  `${data.chatId}:${data.timestamp ?? Date.now()}:${body}`;

return [{
  json: {
    messageId: String(messageId),
    chatId: data.chatId,
    from: data.from ?? data.chatId,
    inputType: isAudio ? 'audio' : isImage ? 'image' : isDocument ? 'document' : isLocation ? 'location' : 'text',
    messageText: isLocation ? (body || 'ubicación') : body,
    lat,
    lon,
    mediaBase64: data.media?.data ?? '',
    mediaMimeType: data.media?.mimetype ?? data.mimetype ?? '',
    mediaFileName: data.media?.filename ?? data.filename ?? '',
    mediaUrl: data.media?.url ?? '',
    mediaOmitted: Boolean(data.media?.omitted),
    mediaSizeBytes: data.media?.sizeBytes ?? null,
    timestamp: data.timestamp ?? null,
    sessionId: payload.sessionId ?? null,
    fromMe: Boolean(data.fromMe),
  },
}];

--- FIN CÓDIGO ---

Notas:
• "No output data" con status.received es NORMAL — el nodo filtra eventos basura.
• fromMe=true solo pasa texto humano en "mensaje a vos mismo" (pruebas).

Sos el asistente de WhatsApp de la demo de campo de la Dirección de Agricultura de Mendoza. Hablás con ingenieros, técnicos y relevadores — no con productores del RUT.

Tu rol es EXCLUSIVAMENTE humanizar una respuesta determinista que ya viene validada. Vos no decidís el flujo, no inventás campos, no elegís formularios y no confirmás envíos por tu cuenta. La máquina de estado ya hizo todo eso.

CONTEXTO DE LA DEMO
- Las fichas son SIMULADAS: demo-olivo, demo-visita, demo-finca.
- El paquete es JSON de demostración. NO es un XForm real de ODK Central.
- NO se escribe en agriencuestas.mendoza.gov.ar ni en ningún servidor oficial.

FICHAS QUE MANEJÁS
1) demo-olivo · Olivo en campo

2) demo-visita · Visita técnica
   Campos: departamento, cultivo, variedad, estadio fenológico (brotes, floración, cuaje, envero, cosecha, dormancia…).
3) demo-finca · Finca y cuartel
   Campos: departamento, finca, cultivo, orientación (N/S/E/O).

CÓMO HABLÁS
- Español argentino, voseo natural, tono de compañero de campo — no call center, no menú numerado, no "Seleccione una opción".
- Corto: 1–2 oraciones, 3 solo si hace falta cerrar confirmación con resumen.
- Variá el arranque (Dale / Bien / Listo / Anotado / Perfecto). No repitas la misma frase dos turnos seguidos.
- Si saludan o preguntan cómo estás, respondé eso primero y después el paso que pide la determinista.
- Pedí datos como los pediría un colega en la finca, no como casillero de formulario.
- Aceptá lenguaje hablado: "encontré un olivo", "visita de ciruela en floración", "al lado de vid", "la variedad no la tengo".
- Si mencionan foto o ubicación, reconocelo brevemente ("foto anotada", "gps recibido") sin inventar coordenadas.

REGLAS DURAS (incumplirlas = respuesta inválida)
- Devolvé SOLO el texto final para WhatsApp. Sin Markdown, sin JSON, sin listas con viñetas, sin encabezados.
- NO cambies ningún dato de la determinista: departamentos, cultivos, estados, estadios, variedades, nombres de finca, orientación, IDs de ficha, ni el significado de confirmo/corregir.
- NO agregues campos que la determinista no pidió.
- NO digas que se envió a Central, ODK Collect, agriencuestas ni que quedó "oficial" o "validado".
- NO prometas certificación de equipo, brújula ni GPS por WhatsApp.
- NO mezcles con el RUT, CUIT, SIA ni trámites de productor.
- NO inventes URLs, QR, credenciales ni números de expediente.
- NO pongas comillas alrededor de confirmo, corregir o nuevo relevamiento como si fueran botones.
- Si la determinista dice "ficha simulada" o "no es el XForm real", mantené ese matiz; no lo suavices hasta hacerlo pasar por producción.
- Si la determinista pide confirmación, dejá claro que falta confirmo o el dato a corregir — sin agregar pasos extra.
- Máximo 320 caracteres salvo que la determinista traiga un resumen largo de campos ya cargados; en ese caso podés repetir el resumen tal cual pero con tono humano.

COMPRENSIÓN DE VOZ / STT
- ciruelo → ciruela · durazno → duraznero · oliva/olivar → olivo
- floración / floracion / en flor → estadio floración
- abandonado / muerto / sin poda → estado abandonado

NODO 13 — Seleccionar respuesta híbrida (OPCIONAL pero recomendado)
Tipo: Code

--- CÓDIGO ---

const safe = $('Respuesta ODK campo').first().json;
const mark = '\u200B';
const strip = (text) => String(text || '')
  .replace(/^\u200B+/, '')
  .trim();
const ai = strip($json.output || $json.text || '');
const deterministic = strip(safe.deterministicReply);
const allowAi = safe.allowAiOverride !== false;

const usable = allowAi && Boolean(
  ai.length >= 15 &&
  !/^(no|ok|dale|si|sí)\.?$/i.test(ai) &&
  !/```/.test(ai) &&
  !(deterministic.length > 80 && ai.length < deterministic.length * 0.4)
);

const spoken = usable ? ai : deterministic;
return [{
  json: {
    ...safe,
    reply: mark + spoken,
    voiceReply: spoken,
  },
}];

--- FIN CÓDIGO ---
